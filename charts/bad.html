плохие графики

как данные врут. и как это заметить.

графики могут врать не фальсифицируя данные. усечённая ось. неправильный тип. 3D-эффект. двойная шкала. каждый из этих приёмов искажает восприятие, сохраняя «точность» цифр.

// сводка антипаттернов
антипаттерн             │ вместо этого
────────────────────────┼──────────────────────────────
усечённая ось           │ начинай с нуля (bar chart)
3D эффект               │ плоский chart
pie с 10+ сегментами    │ horizontal bar
двойная ось             │ два отдельных графика
line для категорий      │ bar chart
радужные цвета          │ монохром + 1 акцент
иконки разного размера  │ bar chart
stacked area            │ line chart
