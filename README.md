# null
Status: active

Личный статичный архив математических объектов, эссе и алгоритмических скетчей.

## Структура

```
null/
├── index.html              сетка карточек разделов
├── styles/main.css         единственная таблица стилей
├── objects/                134 объекта: числа, идеи, нотация, статистика
├── essays/                 110 эссе
├── visuals/                36 интерактивных визуализаций
├── books/                  16 книг
├── music/                  10 альбомов
├── man.html                руководство в формате man-page
├── map.html                граф связей
├── find.html               поиск
├── sitemap.xml             карта сайта, генерируется
├── scripts/                update_counts.py, generate_sitemap.py,
│                           update_meta.py, preflight.py
├── data/links.json         граф: 313 узлов, 1710 рёбер
├── data/build-backlinks.js генератор блоков «упоминается в»
└── graph-health.py         диагностика графа
```

Числа в `man.html` и `index.html` поддерживает `scripts/update_counts.py` —
править их руками не нужно.

`scripts/update_counts.py` про `essays/index.html` не знает вообще.
Оба числа секции — `essay-section-count` в заголовке и `card-num`
в карточке категории вверху страницы — правятся руками при добавлении
эссе. Забыть второе легко: расхождение видно на странице, но ничего
не ломает, и потому живёт долго.

### Счётчики в `essays/index.html`

Три числа рядом никогда не совпадают, и это конвенция, а не ошибка:

| что считаем | сейчас |
| --- | --- |
| записей `essay-item` в индексе | 113 |
| сумма счётчиков секций | 110 |
| файлов `*.html` в `essays/` | 112 |

Расхождение сверху даёт §07: три записи ведут на эссе, которые живут
внутри страниц объектов (`../objects/numbers/constants/pi.html#essay`
и ещё две). В индексе они выставлены, в счётчик секции не входят —
счётчик считает файлы в `essays/`. 113 − 3 = 110.

Расхождение снизу дают две редирект-заглушки, оставшиеся после
переименований (`two-systems.html`, `cognitive-biases.html` →
`oshibki-po-pravilam.html`). `count_pages` в `scripts/update_counts.py`
их отсекает — см. `is_redirect`. 112 − 2 = 110.

Инвариант, который должен держаться: сумма счётчиков секций равна числу
не-редиректных файлов в `essays/`, а в каждой секции счётчик в заголовке
равен числу в карточке категории. Оба проверяет `scripts/preflight.py`.

### Порядок при правке страниц

```
1. правки + update_meta.py + update_counts.py
2. счётчики в essays/index.html руками (два числа на секцию)
3. git add + commit
4. generate_sitemap.py
5. git commit --amend
```

Пункты 3–5 именно в таком порядке: `generate_sitemap.py` берёт `lastmod`
из git, и для незакоммиченной страницы даты нет — запись попадает в карту
без `<lastmod>`. Один раз так и уехало на прод. Теперь скрипт в такой
ситуации ничего не пишет и завершается с ненулевым кодом.

Правило шире, чем «при добавлении страницы»: карту надо перегенерировать
**после любого коммита, меняющего `*.html`**. `<lastmod>` берётся из даты
последнего коммита, тронувшего файл, и меняется от любой правки — включая
машинную. Прогон `data/build-backlinks.js` не добавил ни одной страницы,
но сменил дату 57 файлам, и карта ушла отдельным коммитом уже после пуша.
Отставание карты от коммитов проверяет `scripts/preflight.py`.

Прогон `data/build-backlinks.js` — тоже правка страниц: сначала коммит
рёбер, потом прогон, потом коммит его вывода отдельно от ручного.

Перед пушем — `python3 scripts/preflight.py`.

## `google9b84a06f40ea405c.html` — не удалять, не менять

Файл подтверждения владения ресурсом `https://yzotop.github.io/null/`
в Google Search Console. Лежит в корне репозитория, отдаётся по
`https://yzotop.github.io/null/google9b84a06f40ea405c.html`.

Google перепроверяет подтверждение периодически, а не однократно при
добавлении ресурса. Пропадёт файл — слетит подтверждение, а вместе
с ним данные поиска и возможность отправлять карту сайта.

- содержимое не менять ни на байт, включая завершающий перевод
  строки: его в файле **нет**, размер ровно 53 байта.
  Контроль: `shasum -a 256` даёт
  `ddcd5ce0ab04a37986ed1edaaa1b7ce1ea764c806a52f85fdc1e21af264578c1`
- не переименовывать и не переносить в подпапку: Google запрашивает
  точный путь
- в `sitemap.xml` не добавлять. Само не попадёт: файл внесён
  в `EXCLUDED` в `scripts/generate_sitemap.py`. Без этой строки
  попадёт — генератор обходит **все** `*.html` на диске
- токен один на аккаунт Google, а не на ресурс, поэтому файл тот же,
  что в репозитории `davydov.my`. Это нормально и так задумано

Проверка целостности:

```sh
echo "ddcd5ce0ab04a37986ed1edaaa1b7ce1ea764c806a52f85fdc1e21af264578c1  google9b84a06f40ea405c.html" | shasum -a 256 -c -
```

В `davydov.my` эта проверка стоит в CI и валит сборку при порче
или пропаже. Здесь CI нет — руками, см. пункт в `BACKLOG.md`
того репозитория.

## Зависимости

Сборки нет, пакетов нет, `node_modules` нет — страницы отдаются как есть.
Внешнего кода три источника, все по CDN и без версии в репозитории:

- Google Fonts — Inter, JetBrains Mono, IM Fell English
- Chart.js 4.4.1 с `cdnjs.cloudflare.com` — 7 страниц, и ещё одна
  тянет его же с `cdn.jsdelivr.net`
- d3 7.8.5 с `cdnjs.cloudflare.com` — только `map.html`

JS на сайте есть: собственный `<script>` стоит на 64 страницах из 351 —
интерактивные визуализации в `visuals/` живут на canvas.

Отдельно от страниц лежит `data/build-backlinks.js` — запускается руками
через node, генерирует блоки «упоминается в» из `data/links.json`.
Узел без входящих рёбер он пропускает целиком, поэтому выписанный руками
блок у такого узла остаётся, но графом не подтверждён и на карте не виден.
Вставить блок ему тоже некуда, если на странице нет `<section class="related">`
— он молча пропустит её при живых входящих рёбрах. Оба случая проверяет
`scripts/preflight.py`.

### Подписи в `related` и `backlinks` различаются намеренно

`related` пишется руками, `backlinks` собирает генератор. Поэтому подпись
одной и той же ссылки в двух местах может не совпадать, и это не
рассогласование:

| блок | кто пишет | подпись |
| --- | --- | --- |
| `related` — «связанное» | автор | проза, под контекст страницы |
| `backlinks` — «упоминается в» | `build-backlinks.js` | `title` узла буквально |

Пример: в `objects/notation/alphabets/hebrew.html` стоит «ZFC —
независимость аксиом», тогда как `title` того же узла в графе —
«Математика которую нельзя доказать». Копировать `title` в `related`
ради единообразия не надо: набор ссылок в `related` обязан совпадать
с исходящими рёбрами узла, подписи — нет.
